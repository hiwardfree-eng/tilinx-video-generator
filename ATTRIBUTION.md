## 🙏 Créditos — Agnes Video Generator

Este proyecto es un **rebrand y extensión** de **[Agnes Video Generator](https://platform.agnes-ai.com)**.

- **Las APIs, el backend de tareas, los endpoints y la interfaz web original son de Agnes** — código abierto por su autor.
- TilinX solo hizo: rebrand visual (marca, español, quitar bloque de apoyo), configuración `TILINX_API_KEY` (compat con `AGNES_API_KEY`), y el puente autónomo a TikTok.
- **Las API keys** se obtienen en **https://platform.agnes-ai.com** (gratis) — el proyecto **no incluye** claves propias.

`AGNES_*` / `agnes_*` dentro del código son identificadores internos del proyecto original conservados por compatibilidad.
